# image/prompt/ — AI Prompt Images

This folder contains **reference images** used by the app's AR/AI location recognition system.

## What's Here

Each image is a processed, square-padded (512×512) JPEG of a specific location.
The image contains an embedded `DINOV2_ORB_V1` feature payload in its tail:

```
[JPEG image data...]  [JPEG EOI: FF D9]  DINOV2_ORB_V1::{json}
```

## Payload Format

Generated by the **myembedder** Flutter app. Fields:
- `v` — version string (`DINOV2_ORB_V1`)
- `ts` — timestamp of embedding
- `dino` — 384-dimensional float vector (DINOv2 small, ONNX)
- `rect` — crop rectangle `{l, t, w, h}` from the original image
- `bg` — neutral background color `{r, g, b}` used for padding
- `orb` — up to 100 ORB keypoints, each `{x, y, s, a, r, d}` where `d` = base64 BRIEF descriptor

## File Naming Convention

`<location_id>_<sequence>.jpg`
- e.g. `rasul_birth_place_1.jpg` → `lahir.jpg` (legacy name, kept)

## Usage

```dart
// In Flutter, read and parse:
final bytes = await rootBundle.load('assets/data/image/prompt/lahir.jpg');
final payload = FeaturePayload.parseFromMetadataString(
  String.fromCharCodes(bytes.buffer.asUint8List())
);
```

The `locations.json` entry for each location references these files via the `promptImages` array.
Metadata describing the embedding (dims, count, timestamp) is stored in `locations.json` — NOT re-embedded as a separate field.
